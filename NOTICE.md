# Data sources and licences

The code is the project's own. The map data comes from these sources; every
map shows them in its attribution pin and on its cards.

## Zürich

- Federal Register of Buildings and Dwellings (GWR), BFS -- Swiss open government data (OGD), attribution.
- Official cadastral survey (Amtliche Vermessung) via geodienste.ch -- OGD, attribution.
- swisstopo: swissTLM3D, swissBOUNDARIES3D, swissALTI3D, relief tiles (wmts.geo.admin.ch) -- OGD, attribution.
- BAFU / BFE: road and rail noise models, solar roof suitability -- OGD, attribution.
- Canton of Zürich (maps.zh.ch WFS): zoning, hazards, runoff, noise sensitivity, contaminated sites, hospital lists -- OGD, attribution.
- City of Zürich open data registers (schools, kindergartens, ...) -- OGD, attribution.
- Swiss GTFS timetable (opentransportdata.swiss, via geOps) -- open data, attribution.
- OpenStreetMap contributors -- ODbL 1.0.

## Belgrade

- OpenStreetMap contributors (buildings, roads, water, land use, places), via Overture Maps -- ODbL 1.0. A database derived from them stays under ODbL.
- Overture Maps Foundation, release 2026-10-21.0 (buildings incl. Microsoft ML Buildings, divisions, places) -- ODbL (OSM-derived themes), CDLA-Permissive 2.0 (places).
- Republički geodetski zavod (RGZ) address register, via Overture / OpenAddresses -- Serbian open data licence, attribution.
- Sekretarijat za javni prevoz, Grad Beograd: city and suburban public transport timetables (GTFS), via data.gov.rs -- Serbian open data licence, attribution.
- Agencija za zaštitu životne sredine (SEPA): air-quality stations and hourly values (opendata.kosava.cloud, HVD open data) and verified daily values (data.gov.rs) -- open data under the Serbian e-government law (attribution).
- Copernicus DEM GLO-30, © DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018, provided under COPERNICUS by the European Union and ESA.
